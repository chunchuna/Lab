# LAB 7 — 等距 2D 生存解谜原型

一个纯前端（HTML5 Canvas + 原生 ES Module，零依赖）的等距 2D 游戏原型。
玩家扮演一名被关在封闭实验室里的研究员，从实验床上醒来，在闪烁的灯光下寻找出路。

目标平台是 **TapTap（APK + TapPlay）**，同一套代码在桌面浏览器和手机上都能跑，
自动按设备切换键鼠 / 触屏操作。打成 APK 的步骤见 [`android-shell/README.md`](android-shell/README.md)。

## 运行

```bash
npm start          # 开发服务器 → http://localhost:5173
npm run build      # 打包到 dist/（单文件 IIFE，约 108 KB）
npm run serve:dist # 验证打包产物
```

> 开发时必须通过 HTTP 打开（用了 ES Module），直接双击 `index.html` 不行。
> 打包产物是普通 script，可以在 `file://` 下运行，APK 就是靠这个。
> 首次按键 / 触摸后才会启动音频（浏览器与 WebView 的自动播放策略）。
>
> 想在桌面上预览手机版：`http://localhost:5173/?touch=1`（`?touch=0` 强制键鼠）。

## 操作

### 触屏（手机）

自动检测触屏设备后启用：左下摇杆移动，右下摇杆调朝向（松手保持朝向），
右侧按钮区从内到外是开枪 / 换弹 / 手电，靠近可交互物体时才出现「互动」按钮，
右上角进背包。装备靠拖动，触屏和鼠标是同一套拖拽逻辑。

### 键鼠（桌面）

| 按键 | 功能 |
| --- | --- |
| `W A S D` | 等距移动（W 朝屏幕上方） |
| 鼠标 | 角色朝向 / 瞄准 |
| `E` | 互动（门禁面板、储物柜、实验床） |
| `I` / `B` / `Tab` | 打开背包（拖动装备） |
| `1` / `2` | 快速装备 手电筒 / 手枪 |
| `Q` | 左右手互换 |
| `F` | 手电筒开关 |
| 鼠标左键 | 开枪 |
| `R` | 换弹（消耗背包里的备用弹匣） |
| `V` | 切换「真实视线遮挡」（默认关闭） |
| `H` | 显示/隐藏操作说明 |

## 流程

1. 从实验床上醒来（起身动画 + 睁眼过场）。
2. 走到门口按 `E` → 播放人脸识别扫描动画 → 报错 `ERR_0x37`，门保持锁定。
3. 找到西墙边的应急储物柜，`E` 打开、`E` 取物 → 手电筒、手枪 M1911、2 个备用弹匣进入背包。
4. 打开背包，把手电筒 / 手枪拖到立绘两侧的「左手 / 右手」格子完成装备。
5. 装备手枪后显示准星，左键射击、`R` 换弹。

## 光照与遮挡

两套遮挡是分开的，可以独立理解：

- **光线遮挡（始终开启）**：每个光源都会实时计算一份*可见多边形*（对场景线段做角度排序光线投射），
  灯光只照亮多边形内部，因此箱子、柜子、控制台都会投出真实的动态阴影。
  命中的墙面/物体正面会沿高度方向拉伸，使竖直表面也能被照亮。
- **视线遮挡（`V` 切换，默认关闭）**：把最终光照再用*以玩家为原点*的可见多边形裁剪一次，
  于是被遮挡的区域即使被灯照亮也完全看不见。这段代码完整保留在
  `lighting.finish()` / `computeVisibility()` 中，只是默认改成用整间房的轮廓做裁剪。

关闭时的裁剪遮罩是 `level.js` 里的 `roomVis`（房间外轮廓 + 墙面拉伸），
所以墙外始终是纯黑，看不到房间外面的内容。

### 性能

静态光源（两盏灯管、门口应急灯、绿色安全指示灯、控制台屏幕、火花）位置和遮挡
关系整局都不变，只有亮度在闪，所以启动时按满功率各烘焙成一张贴图，每帧只需
一次 `drawImage` + `globalAlpha`；关闭视线遮挡时的裁剪遮罩同理预烘焙（模糊也
一次做掉）。镜头抖动是整体平移，画贴图时加同样的偏移即可对齐。

实测单帧渲染耗时（软件渲染，844×390，60fps 预算是 16.7ms）：

| 场景 | 耗时 |
| --- | --- |
| 烘焙前，每帧重算静态光 | 2.53 ms |
| 烘焙后，手电开 | 1.11 ms |
| 烘焙后，视线遮挡也开 | 1.98 ms |

`window.__game.noBake = true` 可以切回未烘焙路径做对比。

灯光合成流程（`src/lighting.js`）：

```
light  = ambient + Σ(每盏灯的径向渐变 ∩ 该灯的可见多边形)
light ∩= 裁剪遮罩（roomVis 或玩家可见多边形）
dark   = 纯黑 −(destination-out) light
画面   = 场景 + dark + light * 0.38（加色辉光）
```

手电筒由三层锥形光叠加：窄的高光核心、主光锥、外围散射，
锥形可见多边形由 `computeVisibilityCone()` 计算，所以光束会被家具真实挡住。

## 目录

```
index.html          页面骨架 + HUD/背包/人脸识别终端的 DOM
style.css           HUD、背包、扫描终端样式（em 单位，随画面缩放）
server.js           零依赖静态服务器
src/
  config.js         分辨率、瓦片尺寸、房间大小、武器参数
  iso.js            等距投影、相机、墙面/地面绘制空间变换
  util.js           随机数、色彩、闪烁函数
  art.js            全部程序化像素美术：地板/墙/道具/角色/立绘/图标
  level.js          房间布局、静态图层烘焙、碰撞体、遮挡线段、光源
  visibility.js     可见多边形（360° 与锥形）、射线求交、通视判断
  lighting.js       多光源合成、遮罩裁剪、黑暗层
  fx.js             火花、碎屑、弹壳、烟雾、曳光、弹孔
  inventory.js      物品表、背包数据、拖拽装备
  ui.js             HUD、字幕、人脸识别序列
  audio.js          WebAudio 程序化音效与环境音
  input.js          键鼠、画面缩放与坐标换算
  controls.js       触屏：双摇杆 + 动作按钮，向上层输出与键鼠一致的意图
  main.js           游戏循环、玩家、互动、枪械、渲染
android-shell/      APK 外壳（MainActivity、清单、上架说明）
tools/              headless Chrome 截图 / 回归 / 性能脚本（开发用）
```

`tools/` 里的脚本都只访问本地服务器并把结果写进 `shots/`：

| 脚本 | 用途 |
| --- | --- |
| `build.mjs` | 打包到 `dist/` |
| `mobile.mjs` | 手机横屏视口 + 真实 touch 事件，验证摇杆/按钮/拖拽是否驱动逻辑 |
| `hit.mjs` | 触屏按钮命中诊断：位置、被谁盖住、两两重叠、是否小于 44px |
| `bench.mjs` | 单帧渲染耗时（rAF 限帧看 FPS 测不出余量） |
| `light.mjs` | 各朝向手电筒与遮挡效果截图 |
| `shot.mjs` / `bag.mjs` | 完整流程与背包拖拽回归 |
| `art.mjs` / `zoom.mjs` / `wake.mjs` | 美术检查：全亮、局部放大、起床过场 |

美术全部是运行时用 Canvas 2D 程序化绘制的，没有任何图片资源。
静态部分（地板、两面背墙、门、扫描终端）在启动时烘焙成一张离屏画布，
道具各自烘焙成精灵后按 `x + y` 深度排序绘制。
